# Foundation (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the `feat/foundation` branch. It delivers a Next.js 16 App Router app with TypeScript strict and Tailwind v4, plus the full quality toolchain: lint, format, typecheck, Vitest, Playwright with axe, and Lighthouse CI budgets. All of these run in GitHub Actions, so no later phase can merge broken.

**Architecture:** The app is scaffolded with `create-next-app` into a temp dir and copied into the existing repo, which already holds docs, images and the resume. The home page is a deliberately minimal server-rendered placeholder (name and positioning line) that exists only to give every check a real route to test. Phase 3 replaces it. All absolute URLs flow from one module, `src/lib/site-url.ts`, which reads `NEXT_PUBLIC_SITE_URL`.

**Tech Stack:** Next.js 16.4 (Turbopack, `@tailwindcss/turbopack`, no PostCSS config), React 19.3, TypeScript 5 (`strict`), Tailwind CSS 4, ESLint 9 flat config (`eslint-config-next`), Prettier 3 with `prettier-plugin-tailwindcss`, Vitest 5 with jsdom and React Testing Library 16, Playwright 1.64 with `@axe-core/playwright`, `@lhci/cli` 0.15, GitHub Actions (`actions/checkout@v7`, `actions/setup-node@v7`, `actions/upload-artifact@v7`), Node 24.

**Spec:** `docs/superpowers/specs/2026-09-19-nextjs-portfolio-design.md` (§2, §3, §7 budget, §10, §11 phase 1)

## Global Constraints

- TypeScript `strict: true`. Also enable `noUncheckedIndexedAccess`.
- Tailwind v4 CSS-first. **No `tailwind.config.js`** and no PostCSS config. The scaffold wires Tailwind through `@tailwindcss/turbopack` in `next.config.ts`.
- Never add `output: export`. Server Actions are needed in phase 7.
- All absolute URLs derive from `NEXT_PUBLIC_SITE_URL` and nothing else. Never hardcode a domain.
- Performance budget, mobile: Lighthouse ≥ 0.95 in performance, accessibility, best-practices and seo; LCP < 1500 ms; CLS < 0.02; home-route JS ≤ 122880 bytes transferred (about 120 KB gzipped).
- WCAG 2.1 AA: axe tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, checked in both light and dark color schemes.
- Conventional commits, all on branch `feat/foundation`. Commit identity is `dbsnaveen@gmail.com` (already set in the repo config).
- Node 24 (`.nvmrc`), so `@types/node` must be `^24`. With `^20`, Vitest 5's peer range makes `npm install` fail with ERESOLVE.
- Next 16 ships its own docs at `node_modules/next/dist/docs/` and writes an `AGENTS.md` that tells agents to read them. Consult those docs, not memory, for any Next API question.

## Review Focus

1. **`NEXT_PUBLIC_SITE_URL` set loosely** (`portfolio.vercel.app`, `https://x.dev/`, `https://x.dev/path?q`): metadata should still resolve to the bare `https://` origin. Pinned in Task 3.
2. **`NEXT_PUBLIC_SITE_URL` malformed** (`https://not a url`): the build should fail with a message naming the variable, not ship broken canonical URLs. Pinned in Task 3.
3. **Fresh clone in CI, where `.next/` doesn't exist:** `tsc` fails on the global `LayoutProps` type unless route types are generated first. `typecheck` runs `next typegen` before `tsc`, and the CI job exercises it from a clean checkout. Pinned in Tasks 1 and 7.
4. **Visitor whose OS prefers dark mode:** the page must still pass axe AA contrast. Pinned in Task 5 by running axe under both `colorScheme: "light"` and `"dark"`.
5. **Phone-width viewport (375 px):** no horizontal page scroll. Pinned in Task 5.

- [ ] **Step 3: Implement `src/lib/site-url.ts`**

```ts
export const SITE_URL_FALLBACK = "http://localhost:3000";

export function resolveSiteUrl(raw: string | undefined): URL {
  const value = raw?.trim();
  if (!value) return new URL(SITE_URL_FALLBACK);

  const withProtocol = /^https?:\/\//i.test(value) ? value : `https://${value}`;
  try {
    return new URL(new URL(withProtocol).origin);
  } catch {
    throw new Error(
      `NEXT_PUBLIC_SITE_URL is not a valid URL: "${value}". Expected e.g. https://example.com`,
    );
  }
}

export const siteUrl = resolveSiteUrl(process.env.NEXT_PUBLIC_SITE_URL);
```

test("home renders server-side content", async ({ page }) => {
